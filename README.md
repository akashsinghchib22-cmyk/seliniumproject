# Selenium Login Automation Project

## Overview
This project automates the login functionality of a web application using Selenium WebDriver. It validates user authentication by testing valid and invalid login scenarios.

## Features
- Automated browser launch and navigation
- Username and password input automation
- Login button click action
- Validation of successful login
- Validation of invalid login error messages
- Element interaction using Selenium locators

## Technologies Used
- Selenium WebDriver
- Python
- ChromeDriver
